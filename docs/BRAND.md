# Marca oficial MILTVPLUS

La única marca permitida es el logotipo exacto aportado por el propietario el 13-11-2026. No reemplazar por iconos de stock ni crear variantes. El PNG original debe copiarse a recursos mipmap cuando el archivo binario esté disponible en GitHub; este commit no declara ese recurso integrado.
